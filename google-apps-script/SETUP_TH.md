# เชื่อมฟามCENTกับ Google Sheets

## 1. สร้างฐานข้อมูล

1. สร้าง Google Sheet ใหม่ ตั้งชื่อเช่น `ฟามCENT Database`
2. ไปที่ **ส่วนขยาย → Apps Script**
3. ลบโค้ดตัวอย่าง แล้ววางเนื้อหาจาก `Code.gs`
4. กด **การตั้งค่าโปรเจกต์** เปิดไฟล์ Manifest แล้ววางเนื้อหาจาก `appsscript.json`
5. กลับหน้า Editor เลือกฟังก์ชัน `setupFarmCENT` แล้วกด **Run**
6. อนุญาตสิทธิ์ให้สคริปต์ จากนั้นเปิด **Execution log**
7. คัดลอก `keyId` และ `deviceSecret` เก็บไว้ในที่ปลอดภัย

ระบบจะสร้างแท็บ `Brokers`, `Trades`, `CashFlows`, `Settings`, `FXRates` และ `AuditLog` ให้อัตโนมัติ

แท็บ `FXRates` ดึง USD/THB อ้างอิงล่าสุดด้วย `GOOGLEFINANCE` และฟามCENTจะตรวจเรตใหม่เมื่อเปิดแอป กลับมาออนไลน์ และทุก 30 นาที

## 2. เปิดเป็น Web App

1. กด **Deploy → New deployment → Web app**
2. เลือก **Execute as: Me**
3. เลือกผู้เข้าถึงเป็น **Anyone**
4. กด Deploy แล้วคัดลอก URL ที่ลงท้ายด้วย `/exec`

แม้ Web App ต้องเปิดรับคำขอ แต่ทุกคำขออ่าน/แก้ไขข้อมูลต้องมีลายเซ็น HMAC จาก Device Secret จึงจะผ่าน ระบบไม่เก็บ Secret ไว้ใน GitHub หรือใน Google Sheet

## 3. เชื่อมในฟามCENT

เปิดฟามCENT → **ข้อมูลเชิงลึก → Google Sheets → เชื่อมต่อ** แล้วกรอก:

- Apps Script Web App URL
- Device Key ID
- Device Secret

กด **ทดสอบการเชื่อมต่อ** และบันทึก

## เกณฑ์แปลงเงิน

- ค่าเริ่มต้นบัญชี Cent: `100 USC = 1 USD`
- ดังนั้น `USD = USC ÷ 100`
- และ `THB = USD × อัตรา USD/THB`

อัตรา `USC ต่อ 1 USD` ปรับได้แยกแต่ละบัญชี และระบบบันทึกอัตรา USD/THB ไว้กับทุกรายการเพื่อรักษายอดย้อนหลัง

เรตอัตโนมัติเป็นเรตอ้างอิงซึ่งอาจล่าช้าและต่างจากเรตถอนจริงของโบรกเกอร์ หากถอนเงินจริงให้แก้อัตราของรายการถอนเป็นเรตที่ได้รับจริงเพื่อให้ยอดบาทตรงที่สุด
